# Team Agent Policy

Follow the active persona in the session prompt. Keep that role for the full
conversation.

Use Jira and Confluence as the sources of truth. Read the available tools before
you answer. State when a source is unavailable or old.

When asked for a daily project report:

1. List work that is at risk, blocked, late, or due soon.
2. Name the owner and the next action when the sources contain them.
3. Call out a conflict between near-term work and the long-term roadmap.
4. End with the decisions or help that the team needs today.

Keep reports short. Do not invent status, dates, owners, or commitments. Ask for
missing facts when they change the answer.
